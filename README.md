# ODYSSEY — Mission Control

A cinematic, scroll-driven landing page prototype built with static HTML, CSS, and JavaScript. It includes a system ignition loader, parallax planet hero, scroll-scrubbed telemetry reveal, a pinned Mission Planner transition, responsive layouts, and reduced-motion support.

## Project files

- `index.html` — page structure and content
- `styles.css` — visual system, responsive layouts, and motion
- `app.js` — interactions and scroll behavior
- `assets/` — image assets
